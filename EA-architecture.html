📌 설계 원칙
  • 서버(백엔드) 로직 없이 정적 파일 + Supabase만으로 구성 — 별도 서버 배포/운영 부담이 없음
  • 모든 관리자 전용 쓰기 작업은 SECURITY DEFINER RPC 함수가 아이디·비밀번호를 서버에서 재검증한 뒤에만 실행 (화면의 버튼 숨김은 보조 수단)
  • 테마/언어/평가값 등은 app_settings 테이블을 통해 전 사용자·전 기기에 실시간 공유
  • 화면 단위로 파일을 완전히 분리 — 한 화면을 고쳐도 다른 화면에 영향이 없음 (파일명 코드 규칙은 시스템 > 레이아웃 참고)
  • 도입 후보 ERP(파일럿 프로그램)가 최종 선정되면, 해당 벤더 API 연동을 이 아키텍처의 "향후 확장" 영역에 추가
🔗 관련 화면
  • 시스템 > 레이아웃 — 화면(파일) 간 이동 구조도
  • 구축 설계 > 도출 로직 — 도입평가 점수를 의사결정으로 연결하는 방법
  • 구축 설계 > 데이터 맵핑 — 레거시 데이터 이관 매핑표
